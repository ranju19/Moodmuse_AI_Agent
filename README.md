# 🎧 MoodMuse Ultra

[🌐 Try the Live App on Streamlit »](https://moodmuseaiagent.streamlit.app/)

**MoodMuse Ultra** is an interactive, AI-powered mood-matching app built with **Streamlit**. It helps users explore their emotions by matching each mood to a curated set of content — quotes, songs, YouTube videos, GIFs, colors, and motivational prompts — transforming feelings into a beautiful digital experience.

---

## 💡 Project Summary

This project was developed as part of the **GenAI course final submission**. It combines prompt engineering, mood classification, dynamic content generation, and interface design in a single application.

**Main features include:**
- 🎭 100+ moods, organized across 8 categories
- 💬 Quote + 🎶 Song + 📺 YouTube + 🌈 GIF for every mood
- 🔍 Mood search + category filter
- 🍀 Motivational toast messages
- 📝 Gratitude journaling
- 📲 Auto-generated mood summaries for sharing

---

## 🔧 Tech Stack

- **Frontend/UI**: Streamlit  
- **Backend Logic**: Python  
- **Multimedia Integration**: YouTube embed, Spotify links, Giphy  
- **Design Elements**: Dynamic color palettes, emoji mapping, toast notifications
